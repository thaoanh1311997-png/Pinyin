Đọc PDF có Pinyin 拼音

Kéo file PDF giáo trình (kể cả bản scan) vào đây, trang web sẽ đọc chữ Hán và ghi pinyin có dấu thanh lên trên từng chữ. Mọi thứ chạy ngay trong trình duyệt, file không bị gửi đi đâu.

hoặc kéo thả file vào khung này PDF lấy từ mục Tệp / Files / Tải xuống của điện thoại. Ảnh lấy từ thư viện ảnh.

Ví dụ kết quả

Bấm vào chữ đọc nhiều âm (như 行) để đổi cách đọc

Hoặc dán chữ Hán vào đây

Mẹo sử dụng
  • PDF scan (chụp/quét) phải đọc chữ từ ảnh, mất khoảng 5–15 giây mỗi trang. Lần đầu cần tải dữ liệu chữ Hán (~2 MB), các lần sau nhanh hơn.
  • Nên chọn khoảng trang cần học (ví dụ 12 đến 20) thay vì cả cuốn sách.
  • Bấm "Xem trang gốc" để so với sách. Chữ đọc từ ảnh đôi khi sai, nhất là chữ nhỏ hoặc ảnh mờ.
  • Trang web tự chọn cách đọc theo ngữ cảnh. Nếu chữ nhiều âm (như 行, 长, 得) bị ghi sai, bấm vào chữ đó để đổi cách đọc.
  • Tắt "Hiện pinyin" để tự kiểm tra, bấm vào chữ để xem lại.
