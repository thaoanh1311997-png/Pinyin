Web tự làm phụ đề cho bạnChọn file video/âm thanh: web tự nghe và ghi ra phụ đề. Dán link YouTube: web thử lấy phụ đề có sẵn của video.
Đã có phụ đề? Dán vào đây (không bắt buộc)
Lấy phụ đề YouTube thế nào?
  1. Mở video trên YouTube bằng máy tính, bấm …thêm ở phần mô tả, chọn Hiện bản chép lời.
  2. Chọn ngôn ngữ Tiếng Trung (nếu có), kéo chuột bôi đen từ dòng đầu tới dòng cuối, bấm Ctrl + C.
  3. Dán vào ô Phụ đề tiếng Trung (Ctrl + V). Thời gian đi kèm giúp web dừng đúng từng câu.
  4. Cách khác: vào downsub.com, dán link video, tải phụ đề tiếng Trung dạng .srt, rồi bấm “Mở file phụ đề”.

Video có chữ in sẵn trên hình (không có nút CC) thì YouTube không có bản chép lời. Khi đó bạn gõ hoặc dán câu vào, mỗi câu một dòng, web dùng giọng đọc máy.
